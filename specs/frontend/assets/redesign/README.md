## These are snapshots, not a gated artefact

They are **dated**, not regenerated by `make gate`, and they are *expected* to
go stale — that is the point of a before. Nothing in the build reads them.
They were produced from the real components and the real catalog example
payload, never from a screen capture, so no credential and no running stack
was involved:

```dart
// frontend/app/test/components/zz_before_shots_test.dart, run once with
//   flutter test test/components/zz_before_shots_test.dart --update-goldens
// and deleted afterwards.
setUpAll(() async {
  // The test font draws every glyph as a filled box, so the real Roboto and
  // MaterialIcons are loaded from the SDK's material_fonts artifacts first.
  // Without this the render is legible to a diff and to nobody else.
});

await tester.pumpApp(
  Scaffold(body: Center(child: SizedBox(
    width: designCardWidth,                      // 560 for the ticket
    child: ScenarioComparisonCard(data: scenarioData()),
  ))),
  surfaceSize: const Size(620, 760),             // 620 × 1000 for the ticket
);
await expectLater(
  find.byType(ScenarioComparisonCard),
  matchesGoldenFile('_shots/before_scenario_comparison.png'),
);
```

`scenarioData()` and `readTicketV2(ticketV2Example())` read
`docs/catalog/view-catalog.snapshot.json` through the components' own
harnesses, so what is drawn is the contract's published example — the same
payload the component tests bind.

When the epic ships, add the matching `after_*.png` beside these from the
implemented client and leave both, so the pair is the record.
